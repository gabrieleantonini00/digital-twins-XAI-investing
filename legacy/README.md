# Historical study

These files document the earlier Groq/Llama study and are not inputs to the
current 500-persona OpenAI analysis.

- `Data_100.csv`: original 100-persona pilot dataset; one retained copy.
- `Data_Dictionary_100.md`: original dictionary for that pilot.
- `Manuscript_100.pdf`, `main_100.tex`: historical manuscript and source.
- `simulation_groq_100.py`: original simulation code.

The current data are `../Data_500.csv`; the current manuscript is
`../paper/Manuscript.pdf`. The Git history preserves the previous repository
layout. Additional local prototypes may be kept here without being part of the
published replication package.
